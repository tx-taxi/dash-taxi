Dash explorer documentation

Blocks, transactions and addresses

Search a block height, block hash, transaction ID, transparent Dash address, or supported explorer URL. A 64-character hash may belong to several chains; manual chain selection stays available.

Dash targets one block every 150 seconds. Dark Gravity Wave adjusts difficulty every block. The block subsidy decreases by approximately 7.1% each year.

1 DASH = 100,000,000 duffs. Fee rates use duff/B. Fiat values use the provider's Dash prices and may lag the market.

Privacy and coverage

The transaction and address views show the transparent chain. Dash special transactions include masternode registrations, quorum commitments and Platform withdrawals. Withdrawal fees come from their special payload, not input minus output values.

The pending list contains transactions observed in a node notification feed since this explorer connected. It is not a complete pending pool and does not predict confirmation time.

Read-only API

Requests use the same local origin. Responses carry observation and stale headers. Provider failures return 503; absence returns 404. This local review does not broadcast transactions.
