About dash.tx.taxi

dash.tx.taxi is the Dash explorer in the tx.taxi multi-chain family. It preserves Mempool's proven interface for inspecting blocks, transactions, addresses, mining activity, fee estimates, and the live Dash mempool while using a Dash-specific tx.taxi identity.

Bitcoin-native data

Values are denominated in DASH, duffs, or the selected fiat currency. Fee rates remain duff/B, transaction sizes use bytes, and all block, address, mining, concepts shown by the interface retain their Dash meaning.

Dash Core coverage

Historical blocks and indexed address histories come from Dash Core data. InstantSend observations are shown separately from block confirmations. ChainLock status is not supplied by this provider. Platform state and identities are outside the Core transaction index.

Infrastructure

The explorer reads public Dash network data through its configured backend. Explorer results are informational and can differ from another node's view of the mempool. Always verify payment details in your wallet and use your own node when independent verification matters.
